# FinReportGraph - 智能投顧研報解析與知識圖譜系統

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![PySide6](https://img.shields.io/badge/GUI-PySide6-brightgreen.svg)](https://doc.qt.io/qtforpython-6/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Encoding](https://img.shields.io/badge/Font%20Decoding-Identity--H%20Lossless-purple.svg)]()

> 專為券商與投顧研究報告打造的智慧分析工具庫：支援 PDF 轉結構化 Markdown、特殊字型無損逆向解碼、30字精準摘要自動提煉、PySide6 現代圖形介面一鍵轉換，以及跨市場/產業之互動式知識圖譜可視化。

---

## 🌟 核心特色

1. **特殊字型逆向無損解碼（Font Reverse Decoding）**：
   - 針對部分券商晨訊採用之 `Identity-H` 特殊嵌入字型（無 ToUnicode 表），採用系統字型 GID 逆向映射技術，**100% 精準還原繁體中文與行情表格數值**，杜絕 OCR 圖片辨識之錯字率與雜訊。
2. **金融語意提煉（30字精準摘要）**：
   - 深入提煉大盤點位、核心漲跌驅動力、焦點個股評等與目標價、產業 CPO/先進製程技術亮點，嚴格控制在 **30 字以內繁體中文**。
3. **桌面端 GUI 一鍵轉換工具（Modern PySide6 GUI）**：
   - 支援任意選擇輸入（PDF）與輸出（Markdown）資料夾。
   - 後台非同步多執行緒（QThread），轉換流暢不卡頓。
   - 即時進度條與彩色日誌視窗，支援 Windows 桌面雙擊批次啟動。
4. **全域互動式知識圖譜（Interactive Knowledge Graph）**：
   - 基於 ECharts 構建單一獨立 HTML（`graph/knowledge_graph.html`），本機離線雙擊即可瀏覽。
   - 五大維度色彩分群：**市場板塊**、**投顧報告**、**產業族群**、**核心標的**、**投資觀點**。
   - 具備關鍵字搜尋、分類標籤篩選、力導向拖曳、側邊欄詳情檢視與 Markdown 文件直達跳轉。
5. **終端命令列檢索工具（CLI Query Engine）**：
   - 提供 `query.py` 快速以股票代碼、個股名稱、產業題材查詢相關報告與知識圖譜關聯。

## 🚀 快速上手

### 1. 安裝環境依賴

建議使用 Python 3.10 以上環境：
```bash
git clone https://github.com/dj8111/FinReportGraph.git
cd FinReportGraph
pip install -r requirements.txt
```

### 2. 啟動 GUI 一鍵轉換工具

- **Windows 桌面直接開啟**：直接雙擊根目錄的 **`啟動轉換工具GUI.bat`**。
- **終端機啟動**：
  ```bash
  python gui_converter.py
  ```
  在視窗介面中選擇 PDF 輸入資料夾與 Markdown 輸出資料夾，點擊「🚀 一鍵轉換成 Markdown」即可自動執行批次解析、字型修復與摘要提煉。

### 3. 命令列終端查詢 (`query.py`)

無需開啟瀏覽器即可在命令列快速查詢報告與關聯標的：
```bash
python query.py 3661             # 查詢世芯-KY (關聯報告、支撐壓力與所屬產業)
python query.py 台積電           # 查詢台積電相關報告與供應鏈
python query.py 光通訊           # 查詢光通訊族群與CPO標的 (全新/聯亞/聯鈞等)
python query.py --picks          # 檢視今日焦點股評析 (世芯/聯發科/中砂/營邦/群聯/致新)
python query.py --market 美股    # 篩選美股相關報告
python query.py --list           # 列出全部 15 份報告之 30 字摘要
```

### 4. 瀏覽互動式知識圖譜

使用瀏覽器直接開啟 **`graph/knowledge_graph.html`**，即可進行視覺化探索、縮放拖曳、高亮節點與跳轉文檔。

## 📂 專案目錄結構

```
FinReportGraph/
├── raw/                         # 原始 15 份投顧 PDF 報告
├── markdown/                    # 完整解析後的結構化 Markdown 文檔 (15 篇)
├── graph/
│   ├── knowledge_graph.html     # 互動式知識圖譜可視化 (單檔即開即用)
│   └── knowledge_graph.json     # 111 節點、150 關係邊之結構化數據
├── summaries.json               # 15 份文檔之 30 字摘要與元資料
├── converter_core.py            # 核心轉換與解碼引擎
├── gui_converter.py             # PySide6 圖形化轉換程式
├── query.py                     # 命令列終端快速檢索工具
├── 啟動轉換工具GUI.bat          # Windows 一鍵啟動批次檔
├── run_gui.bat                  # 英文啟動批次檔
├── README.md                    # 專案首頁彙整導覽表
├── 00_報告目錄與摘要彙整.md       # 報告目錄與摘要快速檢索文件
├── KNOWLEDGE_MAP.md             # 知識圖表專屬 Mermaid 架構圖與查詢索引
├── requirements.txt             # 套件依賴清單
├── LICENSE                      # MIT 開源授權
└── .gitignore                   # Git 忽略設定
```
